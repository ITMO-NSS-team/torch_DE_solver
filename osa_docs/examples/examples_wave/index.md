# Wave Equation Examples

## Overview

This module provides a collection of examples demonstrating how to solve wave equations using neural networks within the `torch_DE_solver` framework. It includes implementations for both 1D and 2D wave equations, showcasing various techniques such as adaptive lambdas, mixed precision training, and different optimization algorithms. The examples cover basic problem formulations, heterogeneous media, multi-scale simulations, and weak formulations with periodic boundary conditions.

## Purpose

The primary purpose of this module is to illustrate the application of neural network-based solvers to wave equations. It serves as a practical guide for users looking to understand how to define, train, and evaluate neural networks for approximating solutions to wave equations. By providing a diverse set of examples, the module aims to demonstrate the flexibility and effectiveness of the `torch_DE_solver` framework in handling different types of wave equation problems.
