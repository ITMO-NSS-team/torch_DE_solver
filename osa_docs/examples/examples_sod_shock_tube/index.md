# Examples Sod Shock Tube

## Overview

This module provides example implementations for solving the Sod shock tube problem using neural networks within the PyTorch framework. It includes functions for defining initial conditions, calculating exact solutions, and visualizing the results. The module offers different approaches, including those utilizing automatic differentiation and weak formulations, to demonstrate the capabilities of neural networks in approximating solutions to gas dynamics equations.

## Purpose

The primary purpose of this module is to showcase the application of neural network-based solvers to a specific problem in fluid dynamics: the Sod shock tube. It provides reference implementations for setting up the problem, computing analytical solutions for comparison, and training neural networks to approximate the solution. The module serves as a practical demonstration of how to use the broader `torch_DE_solver` framework for solving partial differential equations, offering insights into problem formulation, model training, and result analysis in the context of shock wave propagation.
