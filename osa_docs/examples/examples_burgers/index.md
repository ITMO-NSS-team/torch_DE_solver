# Examples Burgers

## Overview

This module provides example implementations for solving the Burgers' equation using neural networks within the PyTorch framework. It includes tools for defining, training, and evaluating neural network models for approximating solutions to the 1D and 2D Burgers' equation. The module offers functionalities for problem formulation, model training with various optimization algorithms, and result analysis, including RMSE calculation. Example implementations demonstrate the capabilities of the solver on the Burgers' equation.

## Purpose

The primary purpose of this module is to demonstrate how to solve the Burgers' equation, a nonlinear partial differential equation, using physics-informed neural networks (PINNs) and other neural network-based approaches. It showcases the application of the `torch_DE_solver` framework to a specific problem, providing example code for setting up the domain, boundary conditions, and equation, training the neural network, and evaluating its performance. The module allows users to compare different optimization algorithms and network architectures for solving the Burgers' equation and serves as a starting point for solving other differential equations using the framework.
