# Examples Poisson

## Overview

This module provides several examples of solving the Poisson equation using neural networks within the PyTorch framework. It demonstrates the application of Physics-Informed Neural Networks (PINNs) to solve the Poisson equation in various scenarios, including 1D problems with adaptive lambdas, 2D problems with classic setups, irregular geometries, multiple subdomains, and 3D problems with complex geometries. The module also includes an example of solving an inverse problem related to the Poisson equation.

## Purpose

The primary purpose of this module is to showcase the capabilities of neural networks in solving the Poisson equation under different conditions and complexities. It serves as a practical demonstration of how to set up and train neural networks to approximate solutions to the Poisson equation in various domains and with different boundary conditions. The examples provided can be used as a starting point for developing and testing new neural network-based solvers for similar problems.
