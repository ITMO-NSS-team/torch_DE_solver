# Examples Legendre

## Overview

This module provides example implementations utilizing Legendre polynomials within the `torch_DE_solver` framework. It serves as a demonstration of how to apply neural networks, specifically in conjunction with Legendre polynomials, to solve differential equations.

## Purpose

The purpose of this module is to showcase the application of Legendre polynomials in solving differential equations using neural networks. It offers a practical example for users looking to implement or understand how to integrate specific mathematical functions into their neural network-based differential equation solvers.
