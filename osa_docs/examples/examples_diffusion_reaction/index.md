# Diffusion Reaction Examples

## Overview

This module provides an example implementation of solving diffusion-reaction equations using neural networks within the PyTorch framework. Specifically, it demonstrates the application of neural network-based solvers to the Gray-Scott equations in 2D. The module includes functionality for setting up the problem domain, defining initial conditions, specifying the equations, and constructing the neural network architecture.

## Purpose

The primary purpose of this module is to showcase how to solve diffusion-reaction type of differential equations using neural networks. It offers a concrete example of problem formulation, model training, and performance evaluation, including calculating the Root Mean Squared Error (RMSE) between predicted and exact solutions. This module serves as a practical demonstration of the capabilities of the broader `torch_DE_solver` project for a specific class of differential equations.
