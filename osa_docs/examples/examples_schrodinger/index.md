# Examples Schrodinger

## Overview

This module provides an example implementation for solving the Schrodinger equation using neural networks within the PyTorch framework. It includes tools for defining the potential function and setting up the problem for approximation using neural network-based solvers.

## Purpose

The primary purpose of this module is to demonstrate the application of neural networks to solve the Schrodinger equation. It offers a specific example of problem formulation, defining a potential function, and preparing the problem for solution using the broader framework provided by the `torch_DE_solver` project.
