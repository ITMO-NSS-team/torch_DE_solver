# Heat Equation Examples

## Overview

This module provides several examples of solving the heat equation using neural networks within the PyTorch framework. It includes implementations for 1D and 2D heat equations with various complexities, such as varying coefficients, multi-scale grid resolution, and complex geometries. The module demonstrates how to set up and run simulations, define boundary conditions, and evaluate the performance of neural network-based solvers using metrics like Root Mean Squared Error (RMSE).

## Purpose

The primary purpose of this module is to showcase the application of neural networks to solve different variations of the heat equation. It offers practical examples for users to understand and adapt the `torch_DE_solver` framework to specific heat equation problems. The examples cover a range of scenarios, including:

- Solving the 1D heat equation.
- Simulating the 2D heat equation over long time periods.
- Implementing multi-scale grid resolution for the 2D heat equation.
- Handling spatially varying coefficients in the 2D heat equation.
- Addressing an inverse problem for heat diffusion.
- Solving the 2D heat equation on complex geometries.
- Solving the N-dimentional heat equation.
