# Old Configuration Module

## Overview

This module focuses on fitting differential equations to data using the EPDE (Equation Prediction and Discovery Engine) algorithm. It provides functionality for loading data and performing equation searches to find equations that best fit the provided data. The module is designed to extract resulting equations in a solver-compatible format, facilitating their use in downstream tasks.

## Purpose

The primary purpose of this module is to enable the discovery of differential equations from data using the EPDE algorithm. It aims to provide a tool for identifying equations that accurately model the underlying dynamics of a given dataset. By extracting equations in a solver-compatible format, the module facilitates the integration of discovered equations into neural network-based solvers for further analysis and simulation.
