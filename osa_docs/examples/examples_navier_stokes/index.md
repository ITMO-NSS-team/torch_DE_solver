# Examples Navier Stokes

## Overview

This module provides example implementations for solving the Navier-Stokes equations using neural networks within the PyTorch framework. It includes several pre-configured experiments demonstrating the application of neural network-based solvers to various 2D Navier-Stokes problems. The module focuses on setting up, training, and evaluating neural network models for approximating solutions to fluid dynamics scenarios.

## Purpose

The primary purpose of this module is to showcase the capabilities of the `torch_DE_solver` framework in solving complex fluid dynamics problems. It offers ready-to-use examples for different 2D Navier-Stokes scenarios, such as back step flow, classic boundary conditions, lid-driven flow, and long-time simulations. These examples serve as a starting point for users to understand and adapt the framework for their specific fluid dynamics applications, facilitating the development and comparison of different neural network-based solvers in the context of fluid dynamics.
